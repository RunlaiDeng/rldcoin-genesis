# 通用地区账本候选 V1：冻结规则与实际原生检查

对应白皮书 1.11 的 I1–I6，部分 I7/I9/I10。格式
`RLD-REGIONAL-FIXTURE-V1`；实现位于 `tools/regional-ledger`。本规格定义
独立且不兼容的有界测试候选，不修改既有签名网络。它尚未达到主计划第一步
要求的完整故障/时代规则及独立审查退出条件。

当前修订 8 将普通启动的 IPv4 TCP 接触升级为默认 TLS 1.3、独立固定证书和绑定连接的签名挑战，无自动降级；保留修订 6 的签名先落盘、待包含输入预留与精确命令恢复，以及修订 5 的原生钱包查看/签前复核/收件验证。普通启动默认启用有界中继与原生证据验收；Python 运行时支持目录和 TCP 接触，不升级已采用节点。修订 3 增加[持久签名锁与验证者时代交接](REGIONAL_SIGNER_EPOCHS_V1.md)，保留修订 2 的[终局事故与依赖隔离](REGIONAL_FINALITY_INCIDENTS_V1.md)。旧源码/报告在公开仓库保留；新实现使用新 fixture 根，不能延续旧根。

## 身份和签名编码

Currency 绑定格式、`fixture_only=true`、精确 implementation、唯一起源标签、
准入签名公钥、金额上限、每块奖励与成熟高度数。authority 和 Currency ID
必须由启动者分别固定；包内自报的公钥不能成为信任根。初始状态没有分配。

implementation 是域分离哈希，绑定此工具的 Cargo.toml/lock、build.rs、全部
src 文件，以及当前 rld-core 嵌入的具名源码承诺。源码哈希不证明构建诚实或
批准采用；修改代码后必须重建新的 fixture 根，不能接着旧根运行。

每个地区 Admission 由 Currency authority 签名，绑定货币根、唯一标签、
精确规则版本与四个严格排序的有效 Ed25519 公钥；其域分离 ID 作为候选地区
创世身份。只有 Currency 中的唯一起源标签有原生发行；其他地区额度为零。
这是一种预先授权的离线准入候选；验证者时代已有全旧/全新四签共同交接，地区准入演进、撤销和独立 BFT 资格仍缺。

JSON 字段顺序按 Rust 类型固定，map/set 按键排序。Amount 使用已有 Amount
类型的十进制字符串及 u128 检查算术；高度/nonce 是 u64。每种签名、交易、
输出、区块、检查点及状态哈希都使用独立用途域
`RLD-REGIONAL-FIXTURE-V1:<purpose>\0`。未知字段被拒。签名校验使用已有
rld-core 实现。此格式未构成后量子或无界长期密码资格。

## 价值转换

Spend Intent 绑定货币、当地地区、严格排序且唯一的输入列表、完整输出与
找零、当地费用、可选精确目的地区、收款人/出口总金额、目的费用及包含块的
有效高度上限。每个不同输入所有者都须签署同一完整 Intent，签名严格排序。
普通付款要求输入在包含块高度成熟。输入总额必须等于当地输出、当地费用
和出口总额之和；没有隐式找零或可丢失费用。

Export 仍是 Spend 的源扣除。当前地区认可的已安装检查点必须覆盖每个输入
的创建高度；包括导入后的当地付款产生的新输入。仅成熟不允许再出口。
扣除发生于源块，目的区只能从已通过完整重放和四签的源 Snapshot 中导入。
出口 ID 是完整所有者 Intent 的域分离哈希，记录源/目的、收款人、总金额、
目的费用、当地扣除高度与所有输入依赖的并集。

Import 明确引用 Snapshot ID 与 Export ID；验证已准入的源、精确目的区、
同货币、源终局覆盖、出口归属、依赖存在及永久去重。目的收款金额为出口
总额减目的费用；目的费用成为当地矿工输出，两者均按当地高度成熟。Import
本身不要求源 HTTP、回程收据或实时地球批准。其他来源可在同一目的区按相同
规则导入；未知来源/证据不构成信用。

每个 Coin 携带来源检查点依赖集合；付款/找零/费用保留输入依赖，再出口保留
并集；每次 Import 加入其源 Snapshot。Snapshot 完整携带当地块前缀，其
Import 引用的已验证祖先先于它存在于证据档案，所以依赖按因果 DAG 重放。
此做法有界但不压缩，不能外推至无限循环/历史。

返程执行当前地区新扣除、新终局、新 Export ID 与起点新 Import；初始扣除
仍记录在源的历史出口表，不被释放。时间、失联、运输收件、重发、导入通知
都没有退款转换。付款涉及的已有余额即使远方没有任何服务也可当地执行。

## 出块、检查点和故障

Header 绑定币根、地区创世、精确父块、高度、矿工、命令/状态根、已安装
检查点锚与 nonce；验证真实 SHA-256 域分离 PoW 的首字节为零。这只是便宜
fixture 工作，不是生产难度或安全预算。区块必须连续追加，每个命令与奖励
重算状态根，不接收调用者伪造的余额快照。没有 fork-choice/retarget 或时间。

Snapshot Statement 绑定币根、地区、高度、块、重算状态根及前一检查点 ID；
四个已准入公钥须全部验签。新检查点必须严格增高、完整延伸上个已接受块
前缀，且 previous 精确一致。块引用的每个锚必须能从先前已验证检查点安装。
缺签、旧链、缺祖先、矛盾链及锁回退均拒绝，当前账本不被失败覆盖。

本候选假设这些签名者不形成相冲突授权。持久签名 Agent 与共同时代交接已实现，但没有 BFT 视图切换或部分故障活性。有效矛盾证据现已独立持久保全，按直接/祖先来源隔离新的相关付款/导入/再出口；
恢复事故文件不解除隔离。独立 BFT/重配置与恢复授权仍缺，因此 I7 明确未完成。不能把
四签验证或三组不同 fixture 公钥等同于独立控制者。

## 守恒和持久化

当地每个转换重算 `native_minted + received = U + historical_outbound`。
兼容地区历史集合另核对 `I = U + T`：T 仅计尚未在精确目的历史导入的出口；
历史出口和导入 tombstone 不重复成为资产。费用均为 UTXO 的 U。当前没有
通道/储备，E=0；不能据此宣称完成白皮书完整 `I=U+E+T` 资格。

Journal 保存已采用 fixture 包、证据档案、Block/Finalize 事件。启动从零
重放证据和所有事件，不能直接信任余额。每次变更先在副本上完整验证，再
创建新文件、fsync、rename、目录 fsync；独占 OS 锁阻止同目录并发写。
持久化报错后拒绝本进程再次写入，须重新打开重放，避免在 rename 后错误
返回时从旧内存覆盖新状态。遗留 journal.next 不自动覆盖；接触文件不删除。

8 MiB、256 块、64 检查点、4,096 永久索引等限额均拒绝新增并保留已有状态。
符号链接、损坏 JSON、超额文件或重复/不完整证据不能改变余额。本地路径
是受信任的运营目录，不声称能抵御有权同时改文件的攻击者。

完整旧 Journal 仍可回滚：没有外部单调根、独立档案或长期去重证明。拒绝
旧检查点安装与防旧备份回滚是不同结论。恢复/容量实测只覆盖当前测试范围。

## 默认中继的当前接口

完成固定根的 init 后，普通 CLI 启动（不指定子命令）默认恢复/生成独立传输身份，启用认证发现与有界转发；缺少实际接触时显示等待。可用相邻端仍须适配器与身份配置，不虚构本地广播或跨星际连通。状态分开显示 relay_enabled 与 local_import_mining_enabled；纯中继不自动挖矿、发币或取得终局权限。显式 --miner 后，完整验证的目的证据可由原生代码产生本地导入块；签名终局仍另行授权。

相同签名 packet ID 可经多个符合已签跳数及已访问约束的候选相邻路径转发；每端仍最多四帧、限字节，目的按消息与出口 ID 去重。增量加入节点与优先中继停机后的替代交付有实际目录交换测试；并非容量或物理航路保证。详见[启动及命令](../../tools/regional-ledger/README.md)与[实际三地区报告](../../../regional-native-relay-v4/campaign-report.json)。

## 原生钱包的当前接口

`wallet-view` 从固定信任根下重新重放、加锁的本地账本计算当前可花、未成熟、隔离及可再出口金额。`wallet-prepare` 选择同一所有者最多 16 个合格输入，计算精确当地/目的费用和显式找零，绑定当前货币/地区、到期高度与完整本地日志/事故观察。请求最多 15 个输出，为自动找零保留一项；有效期 1–32 块。输出的 draft 和单独保留的 review commitment 必须供用户复核。

`wallet-sign` 在同一原生存储锁下核对精确 review、重新准备的内容与当前 pin；链、证据、时代或事故改变即拒绝旧预览。只读取同一所有者的私有普通 key file，再用实际原生交易执行规则验证签名/守恒/成熟/当地终局/隔离后返回命令。签名不挖矿；当前 CLI 先把精确命令和输入预留落盘，再返回签名与新 wallet head。调用方在目录外保留最新 head。包含前节点还会重验，当前仍仅单所有者请求，完整产品界面与外部防回滚资格未完成。

`wallet-receipt` 按用户期望的精确币根、源/目的地区、出口 ID、收件人及扣除目的费后的净额独立核对已验证证据和当地历史；缺证据拒绝。状态分开显示证据待导入、已导入未成熟、原输出可花、原输出已花及隔离。原输出已花仍保留永久导入记录，找零/新支付从当前 wallet-view 核对；不会把历史到账额重新当余额。当地可花与可再出口终局分开，运输回执和未知远方状态不参与授权。

8 项 Rust 钱包检查及 2 项真实进程检查已覆盖实际所有者签名、金额/地区/收件人拒绝、当前状态改变/重启、事故隔离、私钥文件约束、跨区待导入/成熟/原输出支付后的状态。其余原生检查保持通过；这些有界公开 fixture 的单机结果不是独立资格、跨设备钱包恢复或已采用网络的上线。

## 持久签名与待包含预留

所有钱包 CLI 先取得节点锁，再取得单独的钱包锁。wallet-init 绑定精确币根、地区、所有者；wallet-view/prepare/sign/recover 核对调用方另存的最新 head。签名记录携带原审阅 draft、原生验过的命令、前驱 head 和当前观察，经私有文件、fsync 与原子替换持久保存后才返回。响应丢失后精确重试返回既有签名；wallet-recover 恢复指定既有命令，不读取私钥、不重新签名。

wallet-view 的 available 排除 SIGNED_PENDING_INCLUSION 记录的输入；ledger.spendable 仅为原生账本金额，不可直接作为新的付款预算。包含、其他当地命令消费输入、或未包含命令的下一个合法包含高度已超过 valid_through，分别显示 INCLUDED_IN_LOCAL_LEDGER、INPUTS_CONSUMED_BY_OTHER_LOCAL_COMMAND 和 EXPIRED_BEFORE_INCLUSION。包含前过期要求当地链头 >= valid_through；运输回执、墙钟、删除保管副本、远方失联均无资格释放预留。**这是未扣除的所有者命令到期，不是对已包含出口退款**；已扣除出口、永久导入记录与新返程规则保持。所有签名记录保留，128 条/8 MiB 满则拒绝新签名。

重开时只完成恰好一条已验证记录的完整中断写入；部分/不兼容字节保留并拒绝。钱包另存 head 在存活时拒绝旧钱包备份；创建/签名时保留的观察也拒绝旧/分叉节点前缀、时代/终局倒退及当时已知事故消失。只读查看不自动落盘新的观察。所有本地状态与 head 一起回滚、旁路复制私钥、独立单调服务与跨设备资格仍未实现；当前预留依赖候选 append-only 历史，不代表未来重组/fork-choice 资格。

本修订新增 8 项持久钱包 Rust 检查；累计 59 项原生检查，4 项钱包 CLI 与 8 项中继 CLI 检查通过。覆盖待包含预算、精确响应恢复、旧钱包/节点备份拒绝、写入失败/中断/损坏、当地到期、真实导入后付款及已包含出口不退款。完整钱包、多所有者、真实适配、通道、BFT、长期密码/归档与独立采用仍是强制门槛。

## 修订 7：实际 IPv4 接触

普通启动默认打开仅本机的临时端口；显式 `--mesh-listen IPv4:PORT` 可固定监听。每个 TCP 接触必须由本地运营者配置字面 IPv4/整数端口与独立核对的邻居传输身份；远方通告不能指定访问 URL。请求/回复验签并绑定网络、指定接收者、随机 nonce 与精确交换哈希。整份交换先验完并持久保存才确认保管；失联、超时、繁忙、容量或写入失败继续保留源证据，确认丢失后重复发送幂等。套接字等待不持有 mesh 锁；发送批次持久轮换，后续证据不因前批失败饿死。

13 项实际套接字检查加原 35 项运输检查通过；59 项原生检查与 12 项原生进程集成保持通过。[实际三地区 TCP campaign](../../../regional-native-tcp-v7/campaign-report.json)无共享运输目录：地球只有在证据确实进入邻居保管后才断开，随后远端原生验收、付款、再出口独立进行；返程需恢复接触。目的传输确认不会形成原生信用，恶意外币证据可收件而拒绝导入。

接入最多两个入站工作线程、每轮四个出站邻居，外层限 20 MiB 加 4,096 字节、内层交换限 20 MiB。三秒只限定地面接入等待，不删除节点/消息、不退款，也不是星际 RTT。接触观测是本进程的历史，重启不把旧观测当作新接触。这是同机实际 IPv4、双向、签名且未加密的地面适配；跨设备、加密、单向/射频/BPv7、物理计划、恶意可用性和独立运行仍未资格化。

## 修订 8：固定 TLS 与连接认证

普通启动的 TCP 默认 TLS 1.3，必须在独立核对邻居身份之外固定其证书 DER SHA-256；禁止 TLS 1.2/未加密自动回退。客户端先核对固定哈希、证书中的精确网络/mesh 身份、自签名及有效期，随后核对服务器签名的新连接挑战；请求必须绑定该挑战，回复绑定挑战、客户端 nonce 与交换哈希。旧连接的合法请求不能在新连接上取得返回证据。TLS 密钥独立于 mesh/钱包/终局钥；客户端身份在 TLS 内通过连接挑战与 mesh 请求签名认证，不声称双向客户端证书 TLS。

证书与钥一起存于私有、独占写入并 fsync 的单一 PEM 文件，重启不换身份；损坏、权限、符号链接和钥/证不配全部拒绝并保留文件。新证书有效期为地面当地 UTC 下的 90 天；过期停止新接触，既有消息和资产不删除或退款。续证、更改固定哈希、丢失/旧备份恢复与延迟撤销须另行独立核对；本修订不提供星际密码时代资格。显式 `--mesh-insecure-tcp` 可进行有签名连接挑战的未加密地面实验，但不接受配置了证书固定的邻居，不是降级路径。

24 项套接字检查连同 35 项运输检查通过，59 项原生和 12 项进程集成保持通过；[TLS 三地区演练](../operations/evidence/regional-native-tls-campaign-20260930.json)仍通过 31 次守恒核对，远端付款/再出口期间没有地球调用。透传代理观察到密文且同一包实际收到；错误证书/身份、降级、连接间重放、过期和私有文件故障均有执行反例。此结果是同机 TLS 地面实现，独立安全审查、跨设备、单向/BPv7、实际计划和长期密码/物理路线仍未完成。
