# 通用地区账本候选 V1：冻结规则与实际原生检查

对应白皮书 1.10 的 I1–I6，部分 I7/I9/I10。格式
`RLD-REGIONAL-FIXTURE-V1`；实现位于 `tools/regional-ledger`。本规格定义
独立且不兼容的有界测试候选，不修改既有签名网络。它尚未达到主计划第一步
要求的完整故障/时代规则及独立审查退出条件。

当前源码修订 3 增加[持久签名锁与验证者时代交接](REGIONAL_SIGNER_EPOCHS_V1.md)，保留修订 2 的[终局事故与依赖隔离](REGIONAL_FINALITY_INCIDENTS_V1.md)。旧源码/报告在公开仓库保留；新实现使用新 fixture 根，不能延续旧根。

## 身份和签名编码

Currency 绑定格式、`fixture_only=true`、精确 implementation、唯一起源标签、
准入签名公钥、金额上限、每块奖励与成熟高度数。authority 和 Currency ID
必须由启动者分别固定；包内自报的公钥不能成为信任根。初始状态没有分配。

implementation 是域分离哈希，绑定此工具的 Cargo.toml/lock、build.rs、全部
src 文件，以及当前 rld-core 嵌入的具名源码承诺。源码哈希不证明构建诚实或
批准采用；修改代码后必须重建新的 fixture 根，不能接着旧根运行。

每个地区 Admission 由 Currency authority 签名，绑定货币根、唯一标签、
精确规则版本与四个严格排序的有效 Ed25519 公钥；其域分离 ID 作为候选地区
创世身份。只有 Currency 中的唯一起源标签有原生发行；其他地区额度为零。
这是一种预先授权的离线准入候选，尚无准入/验证者时代演进或撤销。

JSON 字段顺序按 Rust 类型固定，map/set 按键排序。Amount 使用已有 Amount
类型的十进制字符串及 u128 检查算术；高度/nonce 是 u64。每种签名、交易、
输出、区块、检查点及状态哈希都使用独立用途域
`RLD-REGIONAL-FIXTURE-V1:<purpose>\0`。未知字段被拒。签名校验使用已有
rld-core 实现。此格式未构成后量子或无界长期密码资格。

## 价值转换

Spend Intent 绑定货币、当地地区、严格排序且唯一的输入列表、完整输出与
找零、当地费用、可选精确目的地区、收款人/出口总金额、目的费用及包含块的
有效高度上限。每个不同输入所有者都须签署同一完整 Intent，签名严格排序。
普通付款要求输入在包含块高度成熟。输入总额必须等于当地输出、当地费用
和出口总额之和；没有隐式找零或可丢失费用。

Export 仍是 Spend 的源扣除。当前地区认可的已安装检查点必须覆盖每个输入
的创建高度；包括导入后的当地付款产生的新输入。仅成熟不允许再出口。
扣除发生于源块，目的区只能从已通过完整重放和四签的源 Snapshot 中导入。
出口 ID 是完整所有者 Intent 的域分离哈希，记录源/目的、收款人、总金额、
目的费用、当地扣除高度与所有输入依赖的并集。

Import 明确引用 Snapshot ID 与 Export ID；验证已准入的源、精确目的区、
同货币、源终局覆盖、出口归属、依赖存在及永久去重。目的收款金额为出口
总额减目的费用；目的费用成为当地矿工输出，两者均按当地高度成熟。Import
本身不要求源 HTTP、回程收据或实时地球批准。其他来源可在同一目的区按相同
规则导入；未知来源/证据不构成信用。

每个 Coin 携带来源检查点依赖集合；付款/找零/费用保留输入依赖，再出口保留
并集；每次 Import 加入其源 Snapshot。Snapshot 完整携带当地块前缀，其
Import 引用的已验证祖先先于它存在于证据档案，所以依赖按因果 DAG 重放。
此做法有界但不压缩，不能外推至无限循环/历史。

返程执行当前地区新扣除、新终局、新 Export ID 与起点新 Import；初始扣除
仍记录在源的历史出口表，不被释放。时间、失联、运输收件、重发、导入通知
都没有退款转换。付款涉及的已有余额即使远方没有任何服务也可当地执行。

## 出块、检查点和故障

Header 绑定币根、地区创世、精确父块、高度、矿工、命令/状态根、已安装
检查点锚与 nonce；验证真实 SHA-256 域分离 PoW 的首字节为零。这只是便宜
fixture 工作，不是生产难度或安全预算。区块必须连续追加，每个命令与奖励
重算状态根，不接收调用者伪造的余额快照。没有 fork-choice/retarget 或时间。

Snapshot Statement 绑定币根、地区、高度、块、重算状态根及前一检查点 ID；
四个已准入公钥须全部验签。新检查点必须严格增高、完整延伸上个已接受块
前缀，且 previous 精确一致。块引用的每个锚必须能从先前已验证检查点安装。
缺签、旧链、缺祖先、矛盾链及锁回退均拒绝，当前账本不被失败覆盖。

本候选假设这些签名者不形成相冲突授权。没有持久签名锁进程、BFT 视图切换、
部分故障活性或时代轮换。有效矛盾证据现已独立持久保全，按直接/祖先来源隔离新的相关付款/导入/再出口；
恢复事故文件不解除隔离。时代/BFT 与恢复授权仍缺，因此 I7 明确未完成。不能把
四签验证或三组不同 fixture 公钥等同于独立控制者。

## 守恒和持久化

当地每个转换重算 `native_minted + received = U + historical_outbound`。
兼容地区历史集合另核对 `I = U + T`：T 仅计尚未在精确目的历史导入的出口；
历史出口和导入 tombstone 不重复成为资产。费用均为 UTXO 的 U。当前没有
通道/储备，E=0；不能据此宣称完成白皮书完整 `I=U+E+T` 资格。

Journal 保存已采用 fixture 包、证据档案、Block/Finalize 事件。启动从零
重放证据和所有事件，不能直接信任余额。每次变更先在副本上完整验证，再
创建新文件、fsync、rename、目录 fsync；独占 OS 锁阻止同目录并发写。
持久化报错后拒绝本进程再次写入，须重新打开重放，避免在 rename 后错误
返回时从旧内存覆盖新状态。遗留 journal.next 不自动覆盖；接触文件不删除。

8 MiB、256 块、64 检查点、4,096 永久索引等限额均拒绝新增并保留已有状态。
符号链接、损坏 JSON、超额文件或重复/不完整证据不能改变余额。本地路径
是受信任的运营目录，不声称能抵御有权同时改文件的攻击者。

完整旧 Journal 仍可回滚：没有外部单调根、独立档案或长期去重证明。拒绝
旧检查点安装与防旧备份回滚是不同结论。恢复/容量实测只覆盖当前测试范围。

## 已验证范围和下一步

26 项原生检查及三地区 67 次 CLI campaign 覆盖：离线包固定、真实本地工作、
多输入/所有者、拆分合并/找零/两地费用、多来源进口、当地付款、终局再出口、
新价值返程、每阶段守恒、重复/错区/伪签/缺签/金额溢出/到期/整块失败原子性、
检查点前缀拒绝、磁盘拒写、重启/去重恢复、文件和资源限额。

campaign 对每个操作启动单独原生命令进程；三份磁盘账本先后完成 Earth →
Proxima → Andromeda → Earth，另含 Earth → Andromeda 的第二来源。只通过
邻接联系人显式传递档案；期间 Earth 无进程参与远区付款/再出口。它没有
自动 mesh、常驻节点网络、独立运营者、长期逻辑时间/物理老化或真实星际链路。

事故保全与依赖隔离的有界候选已经落地，资格见专项规格。下一实现顺序：
可复核的地区终局锁/时代协议，
原生自动接触/证据提交和钱包签名前验证，随后通道、长期归档/外部防回滚、
密码演进与独立验收。任何候选结果不允许启动新主网或迁移旧/测试余额。
